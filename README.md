# ClipShare — Anonymous Real-time Chat, Clipboard & Calls

6-digit code + password. QR scan to join. 1-hour quick rooms, 24-hour private Gmail IDs.
Chat, shared clipboard, 2GB file sharing, voice & video calls.

## Quick Start
### Backend
cd backend && npm install
cp .env.example .env   # add MONGODB_URI + JWT_SECRET
npm run dev

### Frontend
cd frontend && npm install
npm run dev
